## Collaboration, triage and release risk

I work with developers and product stakeholders to make defects reproducible and decisions actionable.

- **Defect triage:** agree severity and priority based on user impact, scope, reproducibility, workaround and data-integrity risk—not severity labels alone.
- **Working with developers:** provide concise reproduction steps, environment/build details, expected versus actual behaviour, timestamps and relevant redacted logs or network evidence. I help narrow the issue with API and SQL checks where useful.
- **Retesting and regression:** verify the fix, then test adjacent flows and likely regressions, including retry, restart, connectivity changes and cross-platform behaviour.
- **Release communication:** summarise tested scope, open P0/P1 issues, known limitations and residual risk. A release recommendation should make clear what was tested, what was not, and who accepts any unresolved risk.
- **QA coordination:** have helped coordinate testing and coverage across a team of three QA engineers. This reflects hands-on coordination, not formal people management.
